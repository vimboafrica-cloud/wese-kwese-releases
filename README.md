# Wese~Kwese

A free, offline-first school fees system for Windows: receipts, invoices, debtors,
daily cash, fund tracking, and support for more than one currency (e.g. USD and ZiG).
Runs on one PC in the school office; every other computer just opens it in a browser.

**No source code is published here** — this repository exists only to host the
installer download, below.

## Download

See the [latest release](../../releases/latest) for the current version of
`WeseKwese-Setup.exe`.

## Installing

Run the installer on the PC that will act as your server (an administrator prompt
is needed). Windows will show an "Unknown publisher" warning since the installer
isn't code-signed yet — choose **More info -> Run anyway**. This is expected for a
small independent app, not a sign of a problem.

The installer walks you through the port, time zone, backup folder, and database
choice, then opens your browser on a first-run page to create the first Admin
account.
